## 🎯 About This Repository

This repository documents my practical cybersecurity learning through labs, CTF challenges, independent research, and technical experimentation.

The goal is not only to record solutions, but also to document **how vulnerabilities work, why an exploitation technique succeeds, and what can be learned from the process**.

---

> **Note:** All security testing documented in this repository was performed in authorized lab environments, CTF platforms, or systems specifically designed for security training.
